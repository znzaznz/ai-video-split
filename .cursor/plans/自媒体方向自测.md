# 自媒体方向自测（饮茶）

> **用法**
> 1. 在 Cursor 打开本文件，用预览或直接在 `- [ ]` 上勾选（改成 `- [x]`）。
> 2. 每题 **只选一项**；矛盾时以 **第 17 题** 为准。
> 3. 勾完后看文末 **计分表**，把结果填进「结论」一节。
> 4. 把本文件或「交卷一行」发给 Agent，可生成 **主航道 + 对标号类型 + 明确别碰清单**。
>
> 依据：三份聊天记录（闭源闲聊 / 妮妮 / 最好的豆包）+ 此前对话，非 B 站历史。

## 填不动完整 18 题？用这一节就行

**模棱两可 = 正常。** 方向不是「想出来的」，是 **先排除讨厌的，再试一条能做完的**。下面三选一即可。

### 方式 1：排除法（只勾「6 周内坚决不做」）

勾你 **确定不想** 的（可多选）：

- [ ] 发布会 / 热点日更（没新闻就断粮）
- [ ] 强露脸口播 VLOG
- [ ] 纯差评录屏带货流（计划书那条先不当主号）
- [ ] 文艺长篇讲故事当主业
- [ ] 外网搬运「国内没人做」当主业
- [ ] 每周必须 5 更以上

**剩下来的就是可试范围。** 若全勾了 → 先做 **A 工具/builder 解说**（和你聊天、项目最贴）。

### 方式 2：速通 5 题（每题只选「更像」的一项，不用 100% 确定）

| # | 题 | 选一项 |
|---|-----|--------|
| **T1** | 6 周后更想证明什么？ | [ ] A 有人看 [ ] B 有人找我做事/咨询 [ ] C 赚到钱 [ ] D 我有一套固定拍法 |
| **T2** | 拍一条片最烦的环节？ | [ ] A 想选题 [ ] B 出镜/录音 [ ] C 剪辑 [ ] D 发出去没人看 |
| **T3** | 私下聊嗨的话题更像？ | [ ] A 工具/AI/怎么做成 [ ] B 热点八卦 [ ] C 买啥值不值 [ ] D 人生选择/感情/猫 |
| **T4** | 绝对不想当的主号形象？ | [ ] A 文化散文博主 [ ] B 新闻快讯号 [ ] C 带货矩阵号 [ ] D 都没有/说不清 |
| **T5** | 只能试一个主类 6 周？ | [ ] A 知识/builder [ ] B 资讯 [ ] C 避坑测评 [ ] D 故事 |

**速通交卷：** `T1_ T2_ T3_ T4_ T5_`

### 方式 3：直接认草案（改一个字也行）

根据聊天记录，**先给你一版「够用的默认方向」**，你不用答 18 题：

| 项 | 草案 | 你若不同意只改这项 |
|----|------|-------------------|
| 主类 | **A 知识/builder**（我用工具/AI 把事做成） | |
| 形态 | **录屏 + 字幕** 为主；口播/露脸 **不优先** | |
| 垂类（暂定） | **「开发者/效率党用 AI 做项目」**（可缩成：转写、切片、自动化） | |
| 6 周不做 | 发布会主号、纯带货差评流、文艺故事主号、多垂类混发 | |
| 对标类型 | 5万–30万粉、**结构清晰** 的中号，抄钩子+节奏，不抄脸 | |

回复 Agent 一句即可：**「草案 OK」** / **「主类改 X」** / **「垂类改 X」**。
